مركز بناء مدارس الأحد والعضوية الكنسية

شغّل الملف المطلوب بالضغط عليه مرتين:

01_SundaySchool_Installer.bat      مدارس الأحد: مثبت Windows
02_SundaySchool_Android.bat        مدارس الأحد: تطبيق Android
03_ChurchMembership_Installer.bat  العضوية الكنسية: مثبت Windows
04_ChurchMembership_Android.bat    العضوية الكنسية: تطبيق Android
05_SundaySchool_All.bat            مدارس الأحد: المثبت وتطبيق Android
06_ChurchMembership_All.bat        العضوية الكنسية: المثبت وتطبيق Android
07_Build_Everything.bat            بناء كل شيء للبرنامجين (يشمل مثبت الويب)
08_SundaySchool_WebServer_Installer.bat مدارس الأحد: مثبت خادم الويب (للأجهزة الضعيفة وويندوز 7)

كل النتائج في مجلد Output بجوار هذه الملفات، بأسماء ثابتة:
SundaySchool_Setup.exe
SundaySchool_WebServer_Setup.exe
SundaySchool_Android.apk
ChurchMembership_Setup.exe
ChurchMembership_Android.apk

كل تشغيل يبني Release من مصادر المشروع الحالية.
مثبت Windows يتضمن السيرفر ومدير السيرفر وPostgreSQL ومتطلبات التشغيل.
تطبيق Android ملف APK واحد يشمل المعماريات الثلاث.
تقرأ الأدوات رقم الإصدار الداخلي من pubspec.yaml تلقائيًا؛ لا تحتاج لتغيير أسماء ملفات أو أرقام داخل سكربتات البناء.
تظل أسماء ملفات التسليم ثابتة، والجديد يستبدل السابق بعد نجاح البناء والتحقق من النسخة المنسوخة.
إذا شغّلت ملفًا يبني أكثر من ناتج، لا يبدأ استبدال النواتج إلا بعد نجاح كل خطوات البناء المختارة.
إذا فشل البناء، راجع رسالة الخطأ وسجل التشغيل داخل Logs؛ النواتج السابقة لا تُحذف لبدء بناء جديد.
أغلق ملف المثبت إذا كان قيد التشغيل قبل محاولة استبداله.

Output\BUILD_INFO.json يوضح الإصدار الداخلي وتاريخ البناء والبصمة لكل ملف.
Output\SHA256SUMS.txt يوضح بصمات ملفات التسليم الموجودة.
تعمل ملفات bat من أي مجلد عمل، ولا تحتاج لتشغيلها كمسؤول.
يُفتح مجلد النواتج تلقائيًا بعد النجاح. اضغط أي زر لإغلاق نافذة البناء.
شغّل عملية بناء واحدة من هذا المجلد في كل مرة؛ توجد حماية من تشغيل عمليتين فوق بعض.

إذا نقلت أحد المشروعين أو أردت تغيير مجلد النواتج، عدّل settings.json مرة واحدة.
يمكن أيضًا تحديد مسارات Flutter و.NET وInno Setup في نفس الملف إذا لم تكن الأدوات في PATH.
المتطلبات: Flutter وAndroid SDK/JDK لبناء Android، وأدوات بناء Windows و.NET SDK وInno Setup لبناء المثبت.
قد يحتاج البناء الإنترنت لتنزيل اعتمادات Flutter/.NET/Gradle أو متطلبات Visual C++ إذا لم تكن محفوظة محليًا.

للمعاينة فقط من سطر الأوامر: أضف --plan بعد اسم ملف bat.
للتشغيل الآلي بدون انتظار الضغط على زر: أضف --no-pause.
