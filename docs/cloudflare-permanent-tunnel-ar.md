# رابط Cloudflare ثابت للبرامج

هذه الإعدادات تخص الجهاز الحالي. عنوان Wi-Fi وقت الاختبار هو `192.168.1.4` وقد يتغير مع الراوتر.

| البرنامج | الرابط داخل الشبكة | الخدمة المحلية على جهاز السيرفر |
|---|---|---|
| مدارس الأحد | `http://192.168.1.4:5050` | `http://127.0.0.1:5050` |
| العضوية الكنسية | `http://192.168.1.4:5060` | `http://127.0.0.1:5060` |

## إنشاء الرابط الثابت

قبل نشر مدارس الأحد للعامة، اضبط `Jwt:Secret` في إعدادات السيرفر بقيمة عشوائية خاصة بهذا التثبيت؛ الكود الحالي يحتوي قيمة احتياطية ثابتة عند غياب الإعداد. تغييرها يلغي الجلسات القديمة ويتطلب تسجيل الدخول من جديد. لم أغيّر مفاتيح التشغيل الحالية تلقائيًا. لا تنشر العضوية للعامة قبل تنفيذ حماية الـ API الموضحة أدناه.

1. تحتاج حساب Cloudflare ودومين مضافًا إليه. الرابط العشوائي `trycloudflare.com` مؤقت.
2. من لوحة Cloudflare افتح **Networking → Tunnels → Create Tunnel**، واختر Windows.
3. انسخ أمر تثبيت الموصل الذي تعرضه اللوحة وشغله مرة واحدة في Terminal بصلاحية Administrator على جهاز السيرفر. صورته:

   ```powershell
   cloudflared.exe service install <TUNNEL_TOKEN>
   ```

4. انتظر ظهور النفق بحالة Healthy. من **Routes → Add route → Published application** اربط اسمًا مثل `sunday.example.com` بالخدمة `http://127.0.0.1:5050`.
5. اكتب `https://sunday.example.com` في تطبيق مدارس الأحد، ثم سجل الدخول من جديد.

يمكن لنفس النفق خدمة أكثر من اسم. خدمة cloudflared على Windows مشتركة على الجهاز؛ جهز الموصل مرة واحدة، ولا تحذف خدمته من مدير أحد البرنامجين إذا كان البرنامج الآخر يستخدمها.

الجهاز يحتاج أن يظل يعمل ومتصلًا بالإنترنت، ومدير سيرفر البرنامج يجب أن يعمل تلقائيًا. تثبيت cloudflared وحده لا يشغل قاعدة بيانات البرنامج.

المصدر: [دليل Cloudflare الرسمي](https://developers.cloudflare.com/tunnel/get-started/).

## العضوية الكنسية والوصول الخارجي

واجهة المزامنة الحالية للعضوية تقبل استعلامات البيانات بدون مصادقة على السيرفر؛ تسجيل الدخول الموجود في واجهة التطبيق لا يحمي هذه الواجهة. لذلك لم أنشرها ولم أضف لها مسارًا عامًا. استخدمها داخل شبكة موثوقة، أو عبر اتصال خاص محمي مثل Tailscale/WARP بعد ضبط سياسات الوصول، إلى أن تضاف مصادقة فعلية إلى الـ API. توجيه اسم عام إلى `5060` مباشرة سيعرض بيانات العضوية.

## اتصال الأجهزة داخل الشبكة

إذا نجح الاتصال من الكمبيوتر وفشل من الموبايل، شغل ملف `tool/repair-church-lan.ps1` بصلاحية Administrator. يفتح المنفذين 5050 و5060 للأجهزة الموجودة في نفس الشبكة فقط، ولا يفتح منفذ PostgreSQL.

لاختبار الشبكة من متصفح الموبايل افتح `http://192.168.1.4:5050/health` لمدارس الأحد، أو `http://192.168.1.4:5060/api/auth/ping` للعضوية. يجب أن تظهر استجابة JSON بحالة `ok`. العنوان الأساسي وحده قد يرجع 404 لأنه API وليس صفحة ويب.

تأكد من اتصال الموبايل بنفس شبكة Wi-Fi، وأن شبكة الضيوف أو عزل الأجهزة لا تمنع اتصال الأجهزة ببعضها. لا تستخدم عنوان Tailscale أو محول VirtualBox باعتباره عنوان Wi-Fi.
